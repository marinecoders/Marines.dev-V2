# BILLET DESCRIPTION

The Data Scientist / AI Engineer supports the integration of data-driven decision-making and artificial intelligence capabilities into Marine Corps operations and institutional functions. These Marines serve on cross-functional teams and are responsible for the collection, analysis, visualization, and modeling of data to inform warfighter needs, improve operational efficiency, and enhance command and control (C2) capabilities.

Marines in this billet are expected to develop analytical tools and machine learning models tailored to tactical, operational, or administrative use cases. This may include building dashboards, data pipelines, recommendation systems, or AI-enabled decision support tools for planning, logistics, intelligence, and personnel systems.

This is a technical, self-directed, and impact-oriented billet, requiring Marines to train asynchronously and apply industry-standard methods in data science and AI/ML. Collaboration with software developers, subject matter experts, and operational units is critical to mission success.

# PRIMARY DUTIES AND RESPONSIBILITIES

- Design and execute data analyses to support operational planning, readiness, and performance optimization
- Build and maintain data pipelines, ETL processes, and automated analytics workflows
- Develop machine learning models and AI-enabled tools to solve targeted Marine Corps problems
- Create intuitive data visualizations, dashboards, and decision aids using tools like Power BI, Tableau, Plotly, or open-source libraries
- Collaborate with end users to translate operational challenges into analytical questions and actionable outputs
- Integrate with software development teams (e.g., Marine Coders) to embed analytics and models into functional applications
- Stay abreast of emerging trends in data science, AI/ML, and DoD data initiatives (e.g., JADC2, Project Maven, ADVANA)

# PREFERRED SKILLS AND EXPERIENCE

- Proficiency in Python, R, SQL, or other data science languages and tools
- Experience with pandas, NumPy, Scikit-learn, TensorFlow, PyTorch, or similar frameworks
- Familiarity with data engineering tools (e.g., Airflow, DBT, Spark), cloud platforms, or tactical edge computing
- Ability to analyze and work with structured and unstructured military data sets, including logistics, intelligence, and personnel data
- Prior experience in military operations, operations research, or supporting decision-making with data is highly desirable
