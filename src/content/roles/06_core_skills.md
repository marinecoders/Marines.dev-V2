# FOUNDATIONAL TECHNICAL SKILLS

While the individual roles each bring distinct capabilities to the Marine Coders team, there is a set of foundational skills that all team members should possess. These shared competencies enable collaboration, increase interoperability, and ensure a baseline level of technical fluency across the team.

## Git & Version Control
- Understand basic Git operations: clone, pull, commit, push, branching
- Comfortable using GitHub or GitLab for code and documentation management
- Enables collaboration, version control, and integration with CI/CD workflows

## Setting Up a Local Development Environment
- Ability to install and configure an IDE (e.g., VS Code, IntelliJ, PyCharm)
- Set up local environments using tools like Docker, Python virtual environments, or Node/npm
- Supports local development, debugging, and testing of software

## Command Line Fundamentals
- Navigate directories, manage files, and run scripts via terminal or shell
- Useful across development, data analysis, and deployment tasks

## Understanding of APIs and JSON
- Familiarity with RESTful APIs, including how to test endpoints
- Able to read and work with JSON-formatted data
- Enables integration across systems and services

## Basic Data Literacy
- Understand structured data formats such as CSV, JSON, and SQL
- Able to read and interpret simple datasets and write/read basic queries
- Supports better decision-making, debugging, and development

## Software Development Lifecycle Awareness
- Understands agile concepts like sprints, user stories, and minimum viable products (MVPs)
- Familiar with testing, code review, and deployment cycles

## Security & Operational Discipline
- Basic awareness of DoD cybersecurity principles
- Understands the importance of secure data handling, access control, and compliance
- Critical for developing software in military environments

## Documentation & Communication
- Able to write and read clear README files, usage guides, and process documentation
- Comfortable with collaborative documentation tools (e.g., Markdown, Google Docs)
- Promotes clarity, continuity, and effective collaboration in a distributed team

## Deployment Awareness
- Understands the general process of how code moves from development to production
- Familiar with CI/CD principles and configuration basics (e.g., YAML pipeline files)
- Enables more seamless collaboration with DevSecOps personnel

## UX and User Empathy
- Understands the value of usability, clarity, and responsive interfaces
- Appreciates the importance of user feedback and intuitive design
- Improves coordination with UX designers and leads to more mission-effective tools

# RECOMMENDED TOOLS AND PLATFORMS FOR FAMILIARITY

- GitHub or GitLab (for version control and collaboration)
- Visual Studio Code (or another preferred IDE)
- Docker (basic usage for building and running containers)
- Markdown (for documentation)
- Postman (for API testing and validation)
- Terminal / Command Line
- Common team communication tools (e.g., Slack, Microsoft Teams, Discord, Matrix)
